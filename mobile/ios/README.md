# HostLens iPhone Companion Direction

HostLens should not promise deep system-wide iPhone process telemetry.

## Reality

iPhone does not expose a general third-party interface for system-wide process monitoring across other apps.

## Recommended iPhone role

Use iPhone as a companion app for:

- alert notifications
- quick device status
- account access
- acknowledgement and triage actions

## Apple-specific usage features

If HostLens later explores Apple usage insights, that should be a separate feature track built around Apple-approved Family Controls / Device Activity capabilities and entitlement rules.

That is not the same thing as desktop endpoint monitoring.
